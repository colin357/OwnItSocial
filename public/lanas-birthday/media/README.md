# Lana's Birthday Party — media folder

Drop the party **photos and videos** into this folder. Everything you put here
shows up automatically on the page at **/lanas-birthday**, with view + download
buttons, and a "Download all" button.

## How to add media

1. Copy your photo/video files into this folder
   (`public/lanas-birthday/media/`).
2. Commit and push — Vercel rebuilds the site and the new files appear on the
   page within a couple of minutes.

Files are shown in alphabetical/numeric order by filename, so naming them like
`01.jpg`, `02.jpg`, `03.mp4` keeps them in the order you want.

## Supported file types

- **Photos:** `.jpg` `.jpeg` `.png` `.webp` `.gif` `.avif` `.heic` `.heif`
- **Videos:** `.mp4` `.mov` `.webm` `.m4v` `.ogg`

Tip: `.mp4` (video) and `.jpg` (photos) preview in every browser. `.heic`
photos and `.mov` videos come straight off an iPhone and are always
downloadable, but for the best in-browser preview convert them to `.jpg` /
`.mp4` first.
